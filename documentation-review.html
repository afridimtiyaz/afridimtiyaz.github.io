UI Text Review System

A tool I built to help streamline software interface text reviews by checking existing wording, analyzing screenshots, reviewing Figma screens, and managing a repository of UI text.

Try the Live Demo → Explore Features

Project Overview

Software interfaces contain many types of text, including field labels, buttons, headings, tooltips, descriptions, notifications, and error messages. Reviewing this content consistently requires attention to grammar, terminology, clarity, and existing product conventions.

I built the UI Text Review System to bring several review activities into one place and help make the process more structured and efficient.

The Challenge

UI text reviewers need to compare proposed wording with existing repository entries, identify potential content issues, and maintain consistency across screens. Reviewing screenshots and design files can add further manual work.

The tool brings these activities together in a single interface, with options for reviewing existing text, analyzing visual designs, and managing repository entries.

Key Features

The tool brings together the following capabilities.

01. UI Text Review

Check text against the existing repository and review wording for spelling, grammar, tone, and terminology. Specify the UI element type, such as a button, label, tooltip, or error message.

02. Screenshot Analysis

Upload one or more UI screenshots to extract visible text, compare it with repository entries, and review text that is not found in the repository.

03. Figma VD Review

Provide a Figma file or frame URL and a personal access token to fetch screens and review their UI text.

04. New Key Generation

Describe a UI element to generate a proposed internationalization key, English text, and category. An optional module can provide additional context.

05. Repository Management

Search and filter text entries, view suggested text changes, and import or export repository data using CSV files.

06. Structured Review

Organize UI content by keys, categories, modules, original English text, and suggested text to support a more consistent review process.

How It Works

  1. Choose the input: Enter UI text, upload screenshots, or provide a Figma URL.
  2. Check existing content: Compare text with repository entries where applicable.
  3. Review suggestions: Examine proposed wording and potential content issues.
  4. Manage the repository: Search, filter, import, or export entries as needed.

This describes the intended reviewer workflow; individual steps depend on the selected feature.
